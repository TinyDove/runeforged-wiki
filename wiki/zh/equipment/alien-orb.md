# 异化宝石

异化宝石会把装备变为异化装备，并产生多次随机变化。结果可能大幅增强、削弱，或保留当前词条状态。

## 使用方法

在合成格中放入一件可添加词条的装备和一颗异化宝石。

## 适用装备

- 尚未异化、且可添加词条的装备，包括诅咒装备和符文诅咒装备；
- 仍有剩余异化次数的嗜血符文武器。

## 固定变化

使用后一定会发生：

- 品质变为诅咒；
- 装备名称获得“异化”前缀；
- 耐久完全恢复；

嗜血符文武器每次异化会消耗一次剩余异化次数。

## 随机变化

普通异化进行 `1–5` 次随机变化。每次从当前参与抽取的变化中等概率选择一种；变化池包含一次保留当前词条状态的空变化，其他变化也会根据装备当前状态结算。

| 变化 | 结果 |
| --- | --- |
| 空变化 | 保留当前词条状态 |
| 替换词条 | 随机移除 1 条普通词条，再生成 1 条新词条 |
| 添加负面词条 | 原装备没有负面词条时添加 1 条兼容的诅咒词条；原装备已有负面词条时将其移除 |
| 添加普通词条 | 随机尝试增加 `1–5` 条兼容词条，受剩余容量与可用词条池限制 |
| 改变 Tier | 随机改变 1 条普通词条的 Tier，不会变为 T0，也不会保持原 Tier |
| 重随机数值 | 在当前 Tier 的区间内重新生成 1 条普通词条的数值 |
| 添加 T0 | 装备尚无异化 T0 时，添加 1 条可用的异化 T0 词条 |
| 添加满值 T2 | 添加 1 条当前装备可用的额外封印词条，固定为满值 T2；每次异化最多成功一次 |
| 扭曲最高 Tier 词条 | 将最高 Tier 的一条普通词条数值乘以 0.8–1.5 |
| 强化灌注词条 | 装备已有灌注词条时，将其数值乘以 1.2–1.5 |
| 突破精造品质 | 装备已有有效精造时，把精造品质提高到普通上限以上；每次异化最多成功一次 |

“扭曲最高 Tier 词条”不保证增强，结果最低可能降至原数值的 80%。当扭曲后的普通词条突破 T1 上限并进入 T0 时，数值会固定为该词条的普通 T0 数值。

精造词条不会成为“改变 Tier”“重随机数值”或“扭曲最高 Tier 词条”的目标。“替换词条”如果命中精造词条，精造标记会转移到新词条。

“突破精造品质”的结果最高为 `50.0`。最低值按异化前品质计算：

```text
最低品质 = 30 + (clamp(原品质, 5, 25) - 5) × 0.5
```

因此原品质不高于 5 时，结果范围为 `30–50`；原品质为 25 时，结果范围为 `40–50`。

## 词条数量

抽到“添加普通词条”时，会随机尝试加入 `1–5` 条兼容词条；最终数量取决于剩余空位和可用词条。异化会保留已有的注灵宝石改造，并使用宝石修改后的普通词条容量。

因此，普通词条与诅咒区词条的合计上限为：

| 宝石状态 | 无独立传说词条 | 保留独立传说词条 |
| --- | ---: | ---: |
| 无注灵宝石改造 | 8 | 7 |
| 注灵黑曜石 | 9 | 8 |
| 注灵紫水晶、青金石或红宝石 | 7 | 6 |

## 武器 T0 词条

| 词条 | 效果 | 条件 |
| --- | --- | --- |
| 无限耐久 | 装备不会损耗耐久 | 无 |
| 全伤害 | 全伤害提高 25% | 无 |
| 雷击 | 命中时触发额外雷击 | 装备已有闪电词条 |
| 爆裂 | 命中时产生火焰爆裂 | 装备已有火焰词条 |
| 无视护甲 | 物理攻击采用无视护甲的结算 | 无 |
| 死亡保留 | 玩家死亡时不会掉落该装备 | 无 |

## 护甲 T0 词条

| 词条 | 效果 |
| --- | --- |
| 无限耐久 | 装备不会损耗耐久 |
| 全伤害减免 | 受到的全部伤害降低 20% |
| 缓慢恢复 | 每 5 秒恢复 1 点生命 |
| 死亡保留 | 玩家死亡时不会掉落该装备 |

## 负面词条

异化产生的负面词条与诅咒装备使用同一词条池。完整武器、护甲数值及暴食的触发方式见[诅咒系统](curses.md)。

## 天界异化宝石

天界异化宝石使用相同的变化池与词条容量规则，并进行 `4–6` 次随机变化。
