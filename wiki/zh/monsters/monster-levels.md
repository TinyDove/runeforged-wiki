# 怪物等级

怪物等级由生成位置的区域等级、世界进度、随机等级和精英修正共同形成。等级会影响怪物属性、装备品质、通货掉落概率和灌注进度。

## 区域等级公式

默认区域等级先计算：

```text
floor(
  局部难度 × 5
  + 水平距离贡献
  + 垂直高度/深度贡献
  + 维度加成
)
```

默认距离参数为 `1000` 格一个距离周期、每周期 `+10` 级；下界为 `0`。下界和末地默认各有 `+10` 维度加成。

主世界的深度贡献从 `Y < 50` 开始：从 Y=50 到 Y=0，每下降满 `10` 格增加 `1` 级；低于 Y=0 后，每继续下降满 `5` 格再增加 `1` 级。深度贡献通常最高为 `+15`。下界与末地忽略深度贡献。

高度贡献从 `Y > 100` 开始，每上升满 `20` 格增加 `1` 级，通常最高为 `+15`。首次击败末影龙后，深度贡献按双倍速率计算、上限提高到 `+30`，水平距离贡献的上限也会翻倍；高度贡献保持原规则。

`/rf level` 展示的分解还会区分局部难度、距离、深度、高度、维度、时间、Boss 进度、手动修正和死亡降级，适合核对服务器实际结果。

## 世界进度

| 项目 | 默认值 |
| --- | ---: |
| 每获得 `+1` 时间等级所需天数 | 10 天 |
| 时间等级上限 | 10 |
| 击败末影龙后的等级加成 | 10 |
| 全局最终等级上限 | 100 |
| 生成时随机额外等级上限 | 5 |
| 随机额外等级的阶段系数 | 2.0 |

## 世界等级管理

有权限的玩家可以通过命令锁定或追加世界等级：

- `/rf level set <1–100>`：锁定世界基础等级，替代区域、时间与 Boss 进度计算；
- `/rf level extra <1–100>`：在正常计算或锁定的基础等级上追加指定等级；
- `/rf level clear`：同时清除基础等级锁定与额外等级。

`set` 需要 GameMaster 权限或单人世界所有者身份，并且玩家必须处于创造模式。`extra` 和 `clear` 需要 GameMaster 权限或单人世界所有者身份，但不要求创造模式。这三条管理指令都只能由玩家执行，服务器控制台不能直接使用。

额外等级是世界级持久数据，并在各维度共享。它还会把当前阶段的基础等级上限提高相同数值：例如原本上限为 100、额外等级为 `+25` 时，有效上限变为 125。与基础等级锁定同时存在时，最终基础等级为“锁定等级 + 额外等级”。

设置或清除额外等级不会重新计算已经生成并保存等级的怪物；新数值用于之后首次分配等级的怪物。

`/rf level` 会把基础等级锁定和额外等级分别列出。单只怪物的随机附加等级与精英额外等级仍在基础等级之后计算。

## 等级带来的基础属性成长

默认 `runeforged-monsters.json`：

| 属性 | 每级成长 |
| --- | ---: |
| 最大生命值 | +5% |
| 攻击伤害 | +2% |
| 护甲 | 敌对怪物每级 +0.1，最高计算到 100 级 |

每达到 25、50、75、100 级，还会获得一层阶梯属性：最大生命额外 +25%、攻击伤害额外 +1、护甲额外 +2、护甲韧性额外 +2。阶梯生命值与逐级生命值都会按怪物的基础最大生命计算。

普通怪物的冰霜、闪电和神圣抗性默认为 10%，并且每 25 级再增加 5%；火焰抗性默认不随等级成长。具有固定种族抗性的怪物按其专属弱点或抗性计算，详见[元素、抗性与状态](../combat/elements-and-resistances.md)。

这些成长会与精英词条、原版属性和其他修正共同作用。

## 死亡临时降级

若玩家在受到怪物伤害后的默认 `10` 秒窗口内死亡，会获得个人化的临时等级下调：首次下降 `2` 级；重复死亡会向总计 `-5` 或 `-10` 的目标推进，最低为 `-10`。每半个游戏日默认恢复 `1` 级。输入 `/rf level restore` 可以立即清除当前的个人死亡降级。

该机制改变玩家附近采用的当前基础等级，不会永久删除世界进度。
