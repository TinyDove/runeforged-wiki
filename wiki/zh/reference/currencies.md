# 装备通货速查

所有装备通货的完整条件、天界差异与配方见[装备通货](../equipment/currency-workflow.md)。

## 基础与独立通货

| 通货 | 作用 | 主要限制 |
| --- | --- | --- |
| 塑形石 | 普通装备变为魔法，获得第 1 条词条 | 仅普通装备 |
| 强化石 | 增加 1 条词条，最多 3 条 | 已有 1–2 条词条 |
| 淬炼石 | 增加 1 条词条，达到 4 条后变为稀有 | 不能用于诅咒装备或已满词条装备 |
| 重铸石 | 清除 Runeforged 塑造并修复耐久 | 不能用于传说、任何诅咒装备或带封印词条的装备 |
| 剥离石 | 随机移除 1 条普通词条 | 至少有 1 条普通词条 |
| 忏悔石 | 替换 Tier 最低的普通词条 | 至少有 1 条普通词条 |
| 戒律石 | 重新随机未精造普通词条的数值 | 不改变名称、Tier 和数量；不处理精造词条 |
| 升华石 | 装备变为传说并补足词条 | 普通、魔法或稀有装备 |
| 天界碎片 | 刷新传说词条 | 已拥有传说词条的传说或神话装备；神话保持满值 T0 |
| 封印宝石 | 转为封印诅咒，或刷新诅咒区全部词条 | 至少有 1 条普通词条的稀有装备、普通诅咒或封印诅咒装备 |
| 注灵宝石 | 增加灌注进度或刷新灌注词条 | 非普通品质且允许灌注 |
| 异化宝石 | 转为异化诅咒装备并产生随机变化 | 详见异化章节 |

符文碎片是合成基础通货的材料，不能直接用于装备。

## 天界通货

共有十种基础通货拥有天界版本；重铸石、天界碎片和符文碎片没有天界变体。

| 天界通货 | 与基础版本的主要差异 | 主要限制 |
| --- | --- | --- |
| 天界塑形石 | 随机精造最多 2 条普通主词条；已有 2 条时另选 1 条为精造词条 | 非诅咒且拥有可精造的普通主词条 |
| 天界强化石 | 增加 `1.0–4.0` 精造品质；无精造词条时随机精造 1 条 | 非诅咒且至少有 1 条普通主词条；普通上限 25.0 |
| 天界淬炼石 | 新增词条至少为 T1，并有 `10%` 概率尝试可用的普通 T0 | 与淬炼石相同 |
| 天界剥离石 | 移除列表最下方的普通词条 | 至少有 1 条普通词条 |
| 天界异化宝石 | 补充普通词条后进行 `4–6` 次随机变化 | 与异化宝石相同 |
| 天界封印宝石 | 固定生成 3 条诅咒区词条，至少 1 条 T1 | 与封印宝石相同 |
| 天界注灵宝石 | 无视进度直接生成灌注词条，同一词条抽取 3 次数值取最高 | 目标必须允许继续灌注 |
| 天界忏悔石 | 替换最低 Tier 中列表最上方的词条，并有 `5%` 概率尝试普通 T0 | 至少有 1 条普通词条 |
| 天界戒律石 | 只重随机未精造词条中相对本 Tier 数值最低的一条 | 至少有 1 条未精造普通词条 |
| 天界升华石 | 将传说装备提升为神话，并把保留的传说词条提升为满值 T0 | 仅传说装备 |

精造相关完整规则见[装备精造](../equipment/masterwork.md)；异化与灌注的完整限制分别见[异化宝石](../equipment/alien-orb.md)和[灌注系统](../equipment/infusion.md)。
